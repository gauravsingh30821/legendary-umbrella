# ☔ Legendary Umbrella: The Terminal Chronicles

**Legendary Umbrella** is a lightweight, retro-style text adventure built entirely in Python. Wield the ultimate enchanted parasol, battle hazardous weather elements, and conquer the storm right from your command line interface!

---

## 🚀 Quick Start

Get the game up and running in seconds. No complex installations required!

### Prerequisites
* **Python 3.6 or higher** installed on your system.

### Installation & Running the Game
1. **Download the game script** (`game.py`) into a folder on your computer.
2. Open your **Terminal** (macOS/Linux) or **Command Prompt** (Windows).
3. Navigate to the folder where you saved the file:
   ```bash
   cd path/to/your/folder
   ```
4. Launch the game:
   ```bash
   python game.py
   ```

---

## 🎮 How to Play

Depending on the gameplay mode you generated, use these quick controls to master the storm:

### Controls
* **Turn-Based RPG Mode:** Type `A` to Attack, `B` to Block/Open Canopy, or `Q` to Quit, then press `Enter`.
* **Real-Time Arcade Mode:** Use `A` and `D` (or your Left and Right Arrow keys) to move your umbrella across the screen.

### Core Mechanics
* **The Canopy Shield:** Timing your umbrella openings perfectly will deflect severe elemental damage.
* **Weather Hazards:** Watch out for acid raindrops and lightning monsters—they will rapidly deplete your health pool!
